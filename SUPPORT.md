# Gluon support

Start with the [troubleshooting guide](docs/wiki/Troubleshooting.md) or [check existing issues](https://github.com/dotjxl/gluon/issues). Open a [bug report](https://github.com/dotjxl/gluon/issues/new?template=bug.yml) if the problem persists.

Include the Gluon version, macOS version, Mac chip, Steam build, and game name or App ID. Describe what you expected, what happened, and the smallest reliable way to reproduce it. For launch speed, say whether it was the first launch after starting Steam and include the time from Play to a visible window.

Paste the relevant lines from `gluonctl status` and the [matching log](docs/wiki/Troubleshooting.md#find-the-relevant-log). Review excerpts for account names, local paths, launch arguments, or other private information before posting. The project can work from a short redacted excerpt. Save files, installation bundles, and access credentials are unnecessary.

For a game compatibility report, use the [testing guide](docs/wiki/Testing-and-Compatibility-Reports.md). It covers launch timing, fullscreen, rendering, Steam Input, and Cloud observations.
